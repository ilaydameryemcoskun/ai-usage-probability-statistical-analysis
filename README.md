# Probability and Statistical Analysis (Python)

This project presents a **probability and statistical analysis** of artificial intelligence usage across different sectors and enterprise sizes in Turkey.

The analysis is based on official data and includes descriptive statistics, probability distributions, hypothesis testing, and regression analysis.

---

##  Project Scope

- Analysis of AI usage by sector and enterprise size
- Use of official statistical data (TÜİK)
- Probability distribution evaluation
- Hypothesis testing (ANOVA)
- Regression analysis
- Engineering-oriented interpretation of results

---

##  Tools & Technologies

- Python
- Probability and Statistics
- Data Analysis
- Hypothesis Testing
- Regression Analysis

---

##  Data Source

The dataset used in this project was obtained from official statistics published by the **Turkish Statistical Institute (TÜİK)**.

---

##  How to Run

1. Ensure Python is installed  
2. Run the analysis script:

python analiz.py


3. Review the outputs and statistical results
